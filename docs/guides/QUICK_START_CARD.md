# 🚀 RateSpot MCP Installer - Quick Start

## 📥 Installation (2 minutes)

1. **Download** `RateSpot-MCP-Installer.zip`
2. **Unzip** the file
3. **Right-click** `RateSpot-MCP-Installer.app` → **"Open"**
4. **Click "Open"** in the security dialog (this bypasses the normal macOS warning)
5. **Enter your RateSpot API key** when prompted
6. **Wait** for automatic installation
7. **Done!** Ready to use with Claude

## 🔑 Get Your API Key

- **Existing users**: [app.ratespot.io/account-settings](https://app.ratespot.io/account-settings)
- **New users**: [app.ratespot.io](https://app.ratespot.io) (free account)

## 🔒 Security Warning?

If you see: *"Apple could not verify RateSpot-MCP-Installer is free of malware"*

**This is normal!** The app is unsigned but completely safe.

**Fix:** Right-click the app → "Open" → "Open"

## ❓ Need Node.js?

The installer will guide you to download it from [nodejs.org](https://nodejs.org)

## 🗑️ Uninstall

Go to `~/Applications/RateSpot-MCP` → double-click `uninstall.sh`

---

**That's it!** Your RateSpot MCP server will be ready to use with Claude Desktop in just a few minutes! 🎉
